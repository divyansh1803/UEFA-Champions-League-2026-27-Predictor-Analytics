# ⚽ UEFA Champions League 2026-27 Predictor & Analytics

An interactive **UEFA Champions League 2026/27 prediction and football analytics application** designed to explore team performance, league-phase standings, knockout qualification, player information, and tournament outcomes through a data-driven interface.

🔗 **Live Demo:** https://uefa-champions-league-2026-27-predictor.ai.studio/

---

## 📌 Project Overview

The **UEFA Champions League 2026-27 Predictor** combines an interactive tournament simulator with **sports data analytics and visualization**.

The application models the new 36-team league-phase format, where each club plays eight league-phase matches — four home and four away. The top 8 teams advance directly to the Round of 16, teams ranked 9–24 enter the knockout phase play-offs, and teams ranked 25–36 are eliminated.

The project is designed to demonstrate how football data can be transformed into:

* Team performance metrics
* League standings
* Qualification scenarios
* Match predictions
* Player insights
* Tournament simulations
* Interactive visualizations

# 🏟️ Tournament Structure

The application reflects the current Champions League league-phase structure:

**36 Teams**

⬇️

**8 League-Phase Matches per Team**

⬇️

**Positions 1–8**

→ Direct Round of 16 qualification

**Positions 9–24**

→ Knockout Phase Play-offs

**Positions 25–36**

→ Eliminated

UEFA's 2026/27 regulations define the competition stages as the league phase followed by knockout phase play-offs, Round of 16, quarter-finals, semi-finals and final.
